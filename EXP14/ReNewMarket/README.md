# ReNewMarket demo web app

## Run
Open `index.html` in a modern browser. No build step or server is required.

## Included features
- Responsive second-hand marketplace with Electronics, Furniture, Clothing, Collectibles and other categories.
- Search, category/condition filters and price sorting.
- Seller listing creation with title, description, price, condition and optional image URL.
- Save/favourite listings.
- Buyer checkout demo, transaction history and pickup/delivery preference.
- Direct offer/negotiation flow (simulated).
- Admin sign-in and dashboard for user, category, commodity and order management.
- Order logistics status updates: Pending, Shipped, Received; delete orders.
- Browser localStorage persistence.

## Important demo limitations
This is a front-end prototype. Authentication, user accounts, messaging, payment processing, delivery booking, email/SMS notifications and secure multi-user data storage are simulated or local-only. Do not use real payment or personal information. A production marketplace needs a secure backend, database, verified authentication, payment gateway, moderation, and privacy/security controls.
