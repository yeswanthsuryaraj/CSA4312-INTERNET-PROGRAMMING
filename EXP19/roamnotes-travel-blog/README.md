# Roamnotes Travel Blog

Responsive travel blog demo built with HTML, CSS and vanilla JavaScript.

## Run
Extract the ZIP and open `index.html` in a modern browser. No build step is needed.

## Included
- Editorial-style travel blog homepage and featured stories
- Category filters and destination browsing
- Illustrated interactive destination map; pins open related articles
- Article detail views with photo galleries, travel tips and print/share actions
- Reader comments stored in browser localStorage
- About the traveler section
- Resources: packing checklist, travel tools and booking tips
- Newsletter demo interaction
- Responsive mobile navigation and layouts

## Demo limitations
This is a front-end prototype. Comments and demo content are stored locally in the current browser. Newsletter signup does not send email. Real accounts, server-side comments, a live map/geocoding, media uploads, and mailing-list integration require a backend and third-party service configuration. Photos and fonts load from external services and need internet access.
