# BlossomGifts Web Application

Responsive flower and gift e-commerce demo built with HTML, CSS and vanilla JavaScript.

## Run
1. Extract the ZIP archive.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. The app saves demo data in browser `localStorage`.

## Demo use cases
- Browse popular categories and subcategories on the home page.
- Search, filter and sort flowers and gifts by category and price.
- Add products to cart and place a scheduled delivery order.
- View order history and order status.
- Admin can add, edit, change prices and remove products, and view customer/order details.

## Admin access
To access admin tools, sign in with:
- Name: Store Admin
- Email: `admin@blossom.demo`

The demo sign-in does not use passwords. Admin access is a front-end demonstration only.

## Limitations / production requirements
This is a front-end prototype. It does not process real payments, send actual email/SMS notifications, or provide carrier-grade real-time tracking. Before production, add a secure backend and database, password-based authentication, server-side role permissions, payment gateway, email/SMS provider, delivery partner integration, order audit trail, input validation, privacy/security controls and applicable legal/compliance review. Product image URLs use remote Unsplash images and require internet access.
