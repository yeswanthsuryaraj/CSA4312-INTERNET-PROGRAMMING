RAILCONNECT TRAIN RESERVATION WEB APP (FRONTEND DEMO)

Run:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Search the sample Chennai Central to Bengaluru trains.
4. Select Book, enter passenger details and create a demo booking.
5. Copy the generated PNR into PNR enquiry.
6. Use Cancel demo booking to see the illustrative refund estimate.
7. Open Admin demo to add a sample train schedule.

Included:
- Responsive train reservation UI
- Route, journey date and class search
- Sample train list, timings, fares and availability
- Passenger details and demo checkout
- Generated demo PNR and ticket print view
- PNR lookup for bookings saved in browser
- Demo cancellation and illustrative refund estimate
- Admin demo to add train schedules
- Browser localStorage persistence

IMPORTANT:
This is an educational frontend prototype only. It is NOT connected to Indian Railways,
IRCTC, live seat inventory, real payments, email, or a production database. Demo PNRs
and statuses are not valid for travel. Real deployment requires an authorized railway
inventory/booking integration, secure ASP.NET Core backend, SQL Server, authentication,
payment provider, and email service. Never use this prototype to make travel plans.
