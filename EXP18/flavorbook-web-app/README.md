# FlavorBook — Recipe Sharing Web App

A responsive front-end recipe book and meal-planning application built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract `flavorbook-web-app.zip`.
2. Open `index.html` in a modern browser. No build tools or server are required.

## Features
- Responsive homepage, recipe cards and themed collections
- Search by recipe name, description or ingredients
- Filter by category, cuisine, dietary preference and cooking time
- Recipe details with ingredients, step-by-step instructions, tips and serving-size scaling
- Save favorites (stored in browser localStorage)
- Add and publish custom recipes (stored in browser localStorage)
- Weekly meal planner and generated ingredient shopping list
- Comments for the open recipe, print view and native share/copy action

## Notes
- Includes sample recipes and externally hosted Unsplash photos; internet access is needed for those images and Google Fonts.
- Data is stored locally in the current browser. This demo does not include a server, real user authentication, cloud database, moderation, or cross-device sync. Those require a backend and deployment configuration.
