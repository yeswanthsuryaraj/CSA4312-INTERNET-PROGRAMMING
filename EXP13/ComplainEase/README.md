# ComplainEase demo web application

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No build tools are required.

## Included
- User registration/login and complaint submission form with category, description, address, Google Maps link and evidence filename.
- Complaint reference IDs, status tracking, complaint history and feedback/additional information.
- Officer registration/login, complaint queue, status changes and proof-of-work notes.
- Administrator dashboard: view/delete accounts, create officer credentials, change passwords, view/manage complaints, assign officers, update status, and hide/show selected portal features.
- Help centre, admin contact details, dashboard counts and browser localStorage persistence.

## Important
This is a front-end prototype. It stores demo data in the current browser only. File attachments are recorded by filename rather than uploaded. Email/SMS notifications, real Google Maps integration, secure authentication, role-based server permissions, shared multi-user data, and secure document storage are not implemented. Do not use real personal or sensitive information. A production deployment needs a backend, database, secure file storage, verified email/SMS provider, and security review.
