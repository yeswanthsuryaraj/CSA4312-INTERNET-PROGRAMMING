# Gourmet Haven — Fine Dining Restaurant Website

Responsive restaurant website prototype built using HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet access is needed for remote photography, fonts and the embedded Google Maps view.

## Features
- Luxury restaurant homepage with auto-rotating hero carousel
- Menu categories: starters, mains, desserts and drinks, with descriptions and INR pricing
- Reservation request form with date, time, guest count and occasion
- About/story section and chef profile
- Restaurant photo gallery
- Special events and testimonial sections
- Contact information, embedded Google Map and inquiry form
- Responsive mobile navigation and layouts

## Demo limitations
This is a frontend-only prototype. Reservation and contact forms display demo confirmation messages; they do not send bookings or emails. Address, phone, email, menu, pricing and chef details are fictional sample content. Replace them with the restaurant's real information. Production bookings, payments, email notifications, admin tools and persistent data need a backend.
