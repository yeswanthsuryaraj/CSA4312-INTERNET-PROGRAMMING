TECHSAVVY WEB APP - FRONTEND DEMO

How to run:
1. Extract this ZIP.
2. Open the TechSavvy_WebApp folder.
3. Double-click index.html to open it in a modern browser.
   Alternatively, open the folder in Visual Studio / VS Code and run with a local static server.

Included:
- Responsive electronics storefront UI
- Category browsing and product search
- Product sorting
- Add-to-cart, quantity changes and remove
- Wishlist
- Demo checkout (no real payment)
- Demo admin product addition
- Browser localStorage persistence

Important:
This is a working frontend demonstration. It does not yet connect to ASP.NET Core,
SQL Server, real authentication, real payment processing, or live order fulfilment.
Use it as the UI prototype before connecting the backend.
